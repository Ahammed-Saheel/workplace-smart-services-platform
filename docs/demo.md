# Demo Walkthrough

## 30-second tour

1. Open `/`. The landing page explains the product and links to demo accounts.
2. Log in as `employee@demo.com` (password `Demo@1234`).
3. **Cafeteria** → add a couple of items to the cart → **Cart** → place an order.
4. Open a second browser (or incognito) and log in as `cafeteria@demo.com` →
   **Orders** → accept, prepare, and mark the order ready. The employee's
   notification bell updates within ~20s.
5. Back as the employee: **EV Charging** → pick an available charger → choose
   a time → confirm the simulated payment.
6. Log in as `charging@demo.com` to see that reservation on the operator side.
7. Log in as `admin@demo.com` for the platform-wide dashboard and activity log.

## Suggested full walkthrough per role

**Employee**: register a new account, browse both cafeterias, submit a dish
request, vote in the active poll, place and cancel an order, reserve and
cancel an EV slot, update your profile and password.

**Cafeteria Owner**: toggle an item's availability, add a new menu item,
create a poll, review a dish request and change its status, check Analytics.

**Charging Operator**: add a station, add a charger, change a charger's
status, review reservations, check Analytics.

**Admin**: search/filter users and suspend one, view all cafeterias and
charging stations, browse the activity log.
